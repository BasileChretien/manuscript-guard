# Working in this repository

The rules for working here are in [CLAUDE.md](CLAUDE.md), whichever agent tool reads them:
the commands, the conventions, and the facts about the environment that will bite. Read it
before changing anything. It is kept in one place, and this file only points to it.

One of its rules is missed most often: a pull request leaves the version line in each of the
four version files exactly as `main` has it.

The architecture and the known gaps are in [DESIGN.md](DESIGN.md).
