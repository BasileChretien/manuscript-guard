# Response to the reviewers

This letter is invented for the audit page, with the example paper's two versions. Its
reviewers do not exist.

We thank the reviewers for their careful reading.

**Reviewer 1, comment 1.** The number of students.

We now write "Of 250 eligible students, 164 (66%) took part" in the Abstract.

**Reviewer 1, comment 2.** The confidence outcome.

We added "Confidence rose too (mean difference 0.6, 95% CI 0.2 to 1.0, P = 0.01)" to the
Results.

**Reviewer 2, comment 1.** Causal language.

We revised the Discussion, which now reads "Active learning was followed by better results,
in line with earlier work".

**Reviewer 2, comment 2.** The design.

We added "A randomised trial would show whether the sessions cause the gain" to the
Discussion, and deleted "Data were analysed at two study centres" from the Methods. We also
changed Table 2 as asked.
